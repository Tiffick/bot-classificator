=========================================================
Назначение
=========================================================

Human Model — это центральная модель понимания человека.

Это НЕ профиль пользователя.

Это НЕ память.

Это НЕ история диалога.

Это текущее понимание консультанта.

Именно Human Model должна стать главным объектом, вокруг которого в будущем будет строиться вся система.

=========================================================
Главный принцип
=========================================================

После каждого сообщения консультант должен ответить не только пользователю.

Сначала он должен ответить самому себе:

"Что я теперь понимаю об этом человеке?"

Ответом на этот вопрос и является Human Model.

=========================================================
Что НЕ является Human Model
=========================================================

Не является:

- Telegram-профиль;
- JSON с заполненными полями;
- история сообщений;
- prompt;
- база знаний;
- память пользователя.

=========================================================
Что входит в Human Model
=========================================================

Human Model состоит из нескольких уровней.

---------------------------------------------------------
1. Факты
---------------------------------------------------------

Это информация, в которой консультант уверен.

Например:

- имя;
- возраст;
- рост;
- вес;
- цель;
- семейное положение;
- профессия.

Факты появляются только после подтверждения пользователем.

=========================================================

---------------------------------------------------------
2. Неизвестное
---------------------------------------------------------

Список того, чего консультант ещё не знает.

Например:

- текущий вес;
- длительность проблемы;
- предыдущие попытки;
- причина неудач.

Этот список нужен не для хранения данных.

Он нужен для понимания того, какие пробелы ещё существуют.

=========================================================

---------------------------------------------------------
3. Гипотезы
---------------------------------------------------------

Самая важная часть модели.

Гипотеза — это предположение консультанта.

Например:

- человеку не хватает поддержки;
- проблема эмоциональная;
- главная мотивация — здоровье;
- главная мотивация — внешний вид;
- человек боится очередной неудачи.

Гипотезы никогда не считаются фактами.

Они постоянно уточняются.

=========================================================

---------------------------------------------------------
4. Уверенность
---------------------------------------------------------

Каждая гипотеза должна иметь уровень уверенности.

Например:

10%

35%

80%

100%

Это позволит системе понимать, насколько можно доверять собственным выводам.

=========================================================

---------------------------------------------------------
5. Карта боли
---------------------------------------------------------

Не список симптомов.

А понимание того, что именно беспокоит человека.

Например:

- одежда;
- внешний вид;
- энергия;
- здоровье;
- сон;
- ограничения;
- самооценка.

=========================================================

---------------------------------------------------------
6. Мотивация
---------------------------------------------------------

Не цель.

А причина цели.

Например:

Хочу похудеть.

↓

Почему?

↓

Чтобы нравиться себе.

↓

Почему?

↓

Чтобы снова чувствовать уверенность.

Именно мотивация определяет дальнейшую стратегию консультации.

=========================================================

---------------------------------------------------------
7. Стадия консультации
---------------------------------------------------------

Human Model должна понимать, где сейчас находится человек.

Например:

- знакомство;
- исследование;
- осознание;
- принятие решения;
- сопровождение.

Это не состояние программы.

Это состояние процесса консультации.

=========================================================
Что НЕ хранится
=========================================================

Human Model никогда не хранит:

- историю сообщений;
- системные флаги;
- last_question;
- discovery_complete;
- служебные данные Telegram;
- техническую информацию.

=========================================================
Кто создаёт Human Model
=========================================================

Human Model создаёт исключительно HumanModelEngine.

Никакой другой модуль не должен самостоятельно формировать эту структуру.

=========================================================

В будущем большая часть логики проекта должна работать не с profile.

Именно Human Model должна стать центральным объектом архитектуры цифрового консультанта.
