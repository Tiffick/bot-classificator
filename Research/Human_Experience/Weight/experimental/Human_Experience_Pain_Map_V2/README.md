# Human Experience — Pain Map V2 (исследовательский прототип)

**Цель:** повысить точность узнавания субъективной боли пользователя, а не убедительность психологического ярлыка.

## Состав
- `human_experience_pain_map_v2.json`: 30 новых карт психологических переживаний + 12 карточек предыдущей V1 (в отдельном поле, без автоматического смешивания схем).
- `SOURCES.md`: что действительно было доступно по большим профессиональным книгам.
- `DIALOGUE_RULES.md`: как применять версии, не манипулируя переживаниями.
- `VALIDATION.md`: тестовые ситуации и критерии качества.

## Контракт
1. Human Model — единственный источник утверждений о конкретном пользователе. Human Experience — возможные версии.
2. Не выбирать «самую болезненную» формулировку ради воздействия; выбирать наиболее уместную, опираясь на реальные слова человека.
3. Не обязательно отражать боль в каждом ответе. Иногда нужен простой вопрос или пауза.
4. Одно сильное наблюдение лучше пяти предположений; допускать исправление пользователя.
5. Не применять медицинские и психиатрические диагнозы, не заменять терапию.
6. При сообщениях о пищевом расстройстве, самоповреждении, серьёзных симптомах — не углублять эмоциональную продажу, рекомендовать профильную помощь по ситуации.

## Интеграция
Не включено в production. Прежде требуется выбор релевантных карточек по контексту и проверка на ложные попадания; не грузить весь каталог в каждый запрос без эксперимента.
