===============================================================================
ЗАЧЕМ СУЩЕСТВУЕТ ЭТОТ ДОКУМЕНТ
===============================================================================

Этот документ описывает мышление консультанта.

Не архитектуру.

Не программную реализацию.

Не Prompt.

Не работу LLM.

Он отвечает только на один вопрос:

Как принимает решения настоящий консультант?

Все Engine проекта являются попыткой воспроизвести именно этот процесс мышления.

===============================================================================
ГЛАВНЫЙ ПРИНЦИП
===============================================================================

Настоящий консультант никогда не отвечает сразу.

Сначала он думает.

Ответ —

последний этап процесса.

Не первый.

===============================================================================
ЦИКЛ МЫШЛЕНИЯ
===============================================================================

Каждое сообщение пользователя проходит одинаковый путь.

Получить сообщение

↓

Понять смысл

↓

Обновить Human Model

↓

Построить гипотезы

↓

Оценить уверенность каждой гипотезы

↓

Определить главную цель следующего шага

↓

Выбрать наилучшее воздействие

↓

Сформировать ответ

Каждый Engine отвечает только за один этап этого процесса.

===============================================================================
ПЕРВЫЙ ВОПРОС КОНСУЛЬТАНТА
===============================================================================

После каждого сообщения консультант задаёт себе не вопрос:

"Что ответить?"

Он задаёт вопрос:

"Что я теперь понял о человеке?"

Если понимание не изменилось —

сообщение не принесло новой информации.

===============================================================================
ВТОРОЙ ВОПРОС
===============================================================================

После обновления Human Model консультант спрашивает:

"Что изменилось?"

Каждое сообщение должно изменить модель человека.

Если модель не изменилась —

консультант ничего нового не узнал.

===============================================================================
ТРЕТИЙ ВОПРОС
===============================================================================

После обновления модели консультант спрашивает:

"Что я пока только предполагаю?"

Консультант постоянно строит гипотезы.

Он не считает их фактами.

Каждая гипотеза имеет степень уверенности.

Новые сообщения либо усиливают гипотезу,

либо ослабляют её,

либо полностью опровергают.

===============================================================================
ЧЕТВЁРТЫЙ ВОПРОС
===============================================================================

После построения гипотез консультант спрашивает:

"Чего мне сейчас не хватает для понимания?"

Не любой недостающей информации.

А только той,

которая изменит Human Model.

Если ответ не способен изменить модель,

его не нужно спрашивать.

===============================================================================
ПЯТЫЙ ВОПРОС
===============================================================================

Когда понимание становится достаточно глубоким,

консультант перестаёт собирать информацию.

Теперь он спрашивает:

"Что человеку сейчас важнее всего осознать?"

Это первый момент,

когда начинается настоящее консультирование.

===============================================================================
ШЕСТОЙ ВОПРОС
===============================================================================

После выбора главной идеи консультант спрашивает:

"Какими словами человек легче всего узнает себя?"

Это не выбор красивой фразы.

Это поиск формулировки,

которая вызовет узнавание.

===============================================================================
ГЛАВНЫЙ ОБЪЕКТ МЫШЛЕНИЯ
===============================================================================

Все решения принимаются относительно Human Model.

Сообщения пользователя —

лишь источник данных.

Ответ консультанта —

лишь инструмент воздействия.

Но думает консультант всегда только Human Model.

===============================================================================
ГЛУБИНА ПОНИМАНИЯ
===============================================================================

Понимание имеет глубину.

Сначала консультант знает только факты.

Потом —

связи между фактами.

Потом —

мотивацию.

Потом —

страхи.

Потом —

внутренние противоречия.

Потом —

причины поведения.

Чем глубже Human Model,

тем меньше консультант задаёт вопросов

и тем больше начинает понимать без объяснений.

===============================================================================
ГИПОТЕЗЫ
===============================================================================

Хороший консультант не собирает факты.

Он строит вероятностную модель человека.

Каждая новая информация изменяет вероятность уже существующих гипотез.

Консультант никогда не делает категоричных выводов,

если уверенность недостаточна.

===============================================================================
НЕОПРЕДЕЛЁННОСТЬ
===============================================================================

Неопределённость —

нормальное состояние Human Model.

Консультант не стремится устранить всю неопределённость.

Он стремится уменьшить её настолько,

чтобы принять правильное решение.

===============================================================================
ВЫБОР СЛЕДУЮЩЕГО ШАГА
===============================================================================

Каждый следующий ответ имеет только одну главную цель.

Например:

— уточнить гипотезу;

— проверить предположение;

— углубить понимание;

— показать понимание;

— снизить тревогу;

— помочь увидеть ситуацию иначе;

— подготовить человека к следующему этапу.

Один ответ —

одна главная цель.

===============================================================================
ПОЧЕМУ КОНСУЛЬТАНТ НЕ СПЕШИТ
===============================================================================

Слишком ранние выводы разрушают доверие.

Слишком ранние советы бесполезны.

Слишком ранняя мотивация вызывает сопротивление.

Поэтому консультант сначала понимает.

И только потом помогает.

===============================================================================
КРИТЕРИЙ КАЧЕСТВА МЫШЛЕНИЯ
===============================================================================

После каждого сообщения система должна стать лучше понимать человека,

чем понимала его минуту назад.

Если этого не произошло —

мышление не состоялось.

===============================================================================
ГЛАВНЫЙ ПРИНЦИП
===============================================================================

Консультант никогда не пытается придумать хороший ответ.

Он пытается построить правильную модель человека.

Если модель построена правильно,

хороший ответ становится естественным следствием.

Поэтому главным объектом всей системы является не сообщение пользователя.

И не ответ консультанта.

Главным объектом является процесс понимания человека.
