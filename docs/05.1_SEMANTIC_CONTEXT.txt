===============================================================================
SEMANTIC CONTEXT
===============================================================================

Версия: 1.0

===============================================================================
НАЗНАЧЕНИЕ
===============================================================================

Semantic Context является результатом работы Semantic Engine.

Он содержит смысл сообщения пользователя.

Это первая внутренняя модель данных,
которая создаётся после получения нового сообщения.

Semantic Context не хранит историю человека.

Не содержит выводов.

Не содержит решений.

Не содержит рекомендаций.

Он описывает только то,
что было обнаружено в текущем сообщении пользователя.

===============================================================================
ОТВЕТСТВЕННОСТЬ
===============================================================================

Semantic Context отвечает на вопрос:

Что сообщил пользователь?

И ничего больше.

Он не пытается понять человека.

Он не строит гипотез.

Он не принимает решений.

Он только фиксирует смысл сообщения.

===============================================================================
ВЛАДЕЛЕЦ
===============================================================================

Создаётся:

Semantic Engine

Изменяется:

только Semantic Engine.

Все остальные Engine используют Semantic Context
только для чтения.

===============================================================================
СОДЕРЖАНИЕ
===============================================================================

Semantic Context может содержать информацию
о различных аспектах сообщения.

Например:

-------------------------------------------------------------------------------

Основные темы сообщения.

-------------------------------------------------------------------------------

Намерение пользователя.

-------------------------------------------------------------------------------

Цель обращения.

-------------------------------------------------------------------------------

Вопросы пользователя.

-------------------------------------------------------------------------------

Упомянутые события.

-------------------------------------------------------------------------------

Упомянутые люди.

-------------------------------------------------------------------------------

Упомянутые объекты.

-------------------------------------------------------------------------------

Факты.

-------------------------------------------------------------------------------

Предпочтения.

-------------------------------------------------------------------------------

Ограничения.

-------------------------------------------------------------------------------

Эмоциональные признаки сообщения.

-------------------------------------------------------------------------------

Степень уверенности анализа.

===============================================================================
ПРИНЦИПЫ
===============================================================================

Semantic Context не делает выводов.

Он не отвечает на вопрос:

Почему?

Он отвечает только на вопрос:

Что содержится в сообщении?

Если информация отсутствует,

Semantic Context не пытается её придумать.

Если уверенность анализа низкая,

это должно быть отражено внутри объекта.

===============================================================================
ЖИЗНЕННЫЙ ЦИКЛ
===============================================================================

Каждое новое сообщение пользователя
создаёт новый Semantic Context.

После завершения Consultative Loop

Semantic Context становится частью истории консультации,

но больше не изменяется.

Следующее сообщение создаёт
новый независимый Semantic Context.

===============================================================================
ИСПОЛЬЗОВАНИЕ
===============================================================================

Semantic Context используется:

Human Model Engine

для обновления модели человека.

-------------------------------------------------------------------------------

Reasoning Engine

для анализа текущего сообщения.

-------------------------------------------------------------------------------

Decision Engine

при необходимости уточнения информации.

===============================================================================
ГЛАВНЫЙ ПРИНЦИП
===============================================================================

Semantic Context —

это объективное описание смысла сообщения.

Он не содержит интерпретаций.

Не содержит предположений.

Не содержит решений.

Его задача —

максимально точно передать,
что именно сообщил пользователь,

чтобы остальные Engine могли работать
с единым пониманием сообщения.
