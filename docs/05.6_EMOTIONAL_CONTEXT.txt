===============================================================================
EMOTIONAL CONTEXT
===============================================================================

Версия: 1.0

===============================================================================
НАЗНАЧЕНИЕ
===============================================================================

Emotional Context описывает,

каким должен быть следующий ответ консультанта
с точки зрения эмоциональной подачи.

Он не определяет содержание ответа.

Не принимает решений.

Не изменяет выбранное воздействие.

Его задача —

подобрать такую форму общения,

которая позволит максимально естественно
достичь цели,
определённой Impact Context.

===============================================================================
ОТВЕТСТВЕННОСТЬ
===============================================================================

Emotional Context отвечает только на один вопрос:

Как должен прозвучать следующий ответ?

Он описывает эмоциональную стратегию общения,

но не формулирует сам текст.

===============================================================================
ВЛАДЕЛЕЦ
===============================================================================

Создаётся:

Emotional Engine.

Изменяется:

только Emotional Engine.

Все остальные Engine используют
Emotional Context только для чтения.

===============================================================================
СОДЕРЖАНИЕ
===============================================================================

Emotional Context может содержать:

-------------------------------------------------------------------------------

Предпочтительный эмоциональный тон.

-------------------------------------------------------------------------------

Желаемую степень эмпатии.

-------------------------------------------------------------------------------

Степень уверенности речи.

-------------------------------------------------------------------------------

Желаемую глубину объяснений.

-------------------------------------------------------------------------------

Предпочтительный уровень инициативности.

-------------------------------------------------------------------------------

Допустимую прямоту высказываний.

-------------------------------------------------------------------------------

Предпочтительную длину ответа.

-------------------------------------------------------------------------------

Особенности обращения
к конкретному человеку.

===============================================================================
ПРИНЦИПЫ
===============================================================================

Эмоциональная форма ответа
всегда подчиняется цели консультации.

Если человеку требуется поддержка,

форма общения становится более мягкой.

Если требуется помочь увидеть проблему,

форма может стать более прямой.

Если человеку необходимо почувствовать уверенность,

ответ становится спокойным
и уверенным.

Эмоциональная подача
никогда не существует сама по себе.

Она всегда служит цели,
определённой предыдущими этапами мышления.

===============================================================================

===============================================================================

-------------------------------------------------------------------------------

-------------------------------------------------------------------------------

===============================================================================
ЖИЗНЕННЫЙ ЦИКЛ
===============================================================================

Каждый Consultative Loop
создаёт новый Emotional Context.

После формирования ответа

Emotional Context становится частью истории консультации

и больше не изменяется.

===============================================================================
ИСПОЛЬЗОВАНИЕ
===============================================================================

Emotional Context используется
при генерации окончательного ответа.

Он определяет,

каким образом выбранное содержание
будет выражено словами.

Он не изменяет смысл ответа,

а управляет его восприятием.

===============================================================================
ГЛАВНЫЙ ПРИНЦИП
===============================================================================

Emotional Context —

это описание формы общения консультанта.

Он отвечает не на вопрос:

"Что сказать?"

и даже не на вопрос:

"Какого эффекта достичь?"

Он отвечает на вопрос:

"Каким человеком должен прозвучать консультант
в этом ответе?"

Именно Emotional Context завершает внутренний цикл мышления,

превращая принятое решение

в естественную человеческую коммуникацию.
