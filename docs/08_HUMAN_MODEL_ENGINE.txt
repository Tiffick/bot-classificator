===============================================================================
HUMAN MODEL ENGINE
===============================================================================

Версия: 1.0

===============================================================================
НАЗНАЧЕНИЕ
===============================================================================

Human Model Engine отвечает
за постепенное построение
и развитие Human Model.

Он является первым Engine,

который начинает думать
не о сообщении,

а о человеке.

Каждое новое сообщение пользователя
должно сделать Human Model
немного точнее,
глубже
и полезнее
для последующих этапов консультации.

===============================================================================
ОТВЕТСТВЕННОСТЬ
===============================================================================

Human Model Engine отвечает только
на один вопрос:

Что нового стало известно
о человеке?

Он обновляет Human Model,

используя:

• Semantic Context;

• предыдущую Human Model;

• накопленную Memory.

===============================================================================
ВХОДНЫЕ ДАННЫЕ
===============================================================================

Human Model Engine получает:

-------------------------------------------------------------------------------

Semantic Context.

-------------------------------------------------------------------------------

Предыдущую Human Model.

-------------------------------------------------------------------------------

Memory пользователя.

===============================================================================
ВЫХОДНЫЕ ДАННЫЕ
===============================================================================

Результатом работы является

обновлённая Human Model.

После завершения работы

именно эта версия Human Model

становится единственным актуальным
представлением человека
для остальных Engine.

===============================================================================
ЧТО ДЕЛАЕТ HUMAN MODEL ENGINE
===============================================================================

Добавляет новую информацию
о человеке.

-------------------------------------------------------------------------------

Уточняет существующие представления.

-------------------------------------------------------------------------------

Повышает или снижает
уверенность существующих гипотез.

-------------------------------------------------------------------------------

Обнаруживает новые связи
между уже известными фактами.

-------------------------------------------------------------------------------

Исправляет ошибочные предположения.

-------------------------------------------------------------------------------

Удаляет устаревшие
или опровергнутые гипотезы.

-------------------------------------------------------------------------------

Повышает общую глубину
понимания человека.

===============================================================================
ЧЕГО НЕ ДЕЛАЕТ HUMAN MODEL ENGINE
===============================================================================

Не принимает решений.

-------------------------------------------------------------------------------

Не определяет следующий вопрос.

-------------------------------------------------------------------------------

Не строит стратегию консультации.

-------------------------------------------------------------------------------

Не определяет воздействие.

-------------------------------------------------------------------------------

Не формирует ответ.

===============================================================================
ПРИНЦИПЫ РАБОТЫ
===============================================================================

Human Model постоянно развивается.

Она никогда не считается завершённой.

Каждое сообщение пользователя
может изменить существующее понимание.

Новая информация
имеет приоритет
над предыдущими предположениями.

Если новая информация
противоречит существующей модели,

движок обязан
не игнорировать противоречие,

а пересмотреть Human Model.

===============================================================================
РАБОТА С НЕОПРЕДЕЛЁННОСТЬЮ
===============================================================================

Human Model Engine
не стремится устранить
всю неопределённость.

Если информации недостаточно,

неопределённость
сохраняется внутри модели.

Движок предпочитает
честную неопределённость

ложной уверенности.

===============================================================================
ВЗАИМОДЕЙСТВИЕ С ДРУГИМИ ENGINE
===============================================================================

Human Model Engine получает:

Semantic Context.

После обновления модели

передаёт Human Model

Reasoning Engine.

На этом его работа
в текущем Consultative Loop
завершается.

===============================================================================
КРИТЕРИЙ КАЧЕСТВА
===============================================================================

Работа Human Model Engine
считается успешной,

если после каждого сообщения

Human Model
лучше объясняет человека,

чем объясняла его
до получения этого сообщения.

Главная задача —

не накопить больше информации,

а увеличить качество понимания.

===============================================================================
ГЛАВНЫЙ ПРИНЦИП
===============================================================================

Human Model Engine —

это слой понимания консультанта.

Именно здесь

разрозненные сообщения пользователя

впервые превращаются

в целостную картину человека.

Если Human Model построена правильно,

все последующие решения
становятся значительно проще.

Поэтому Human Model Engine
является центральным элементом
всей системы мышления консультанта.
