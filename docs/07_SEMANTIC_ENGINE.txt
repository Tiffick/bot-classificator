===============================================================================
SEMANTIC ENGINE
===============================================================================

Версия: 1.0

===============================================================================
НАЗНАЧЕНИЕ
===============================================================================

Semantic Engine является первым Engine,
который начинает работу после получения
нового сообщения пользователя.

Его задача —

понять смысл сообщения.

Semantic Engine не пытается понять человека.

Не строит Human Model.

Не делает выводов.

Не принимает решений.

Он отвечает только за интерпретацию
текущего сообщения.

===============================================================================
ОТВЕТСТВЕННОСТЬ
===============================================================================

Semantic Engine отвечает только на один вопрос:

Что означает сообщение пользователя?

Он преобразует неструктурированный текст
в Semantic Context,

который затем используется
остальными Engine.

===============================================================================
ВХОДНЫЕ ДАННЫЕ
===============================================================================

Semantic Engine получает:

-------------------------------------------------------------------------------

Сообщение пользователя.

-------------------------------------------------------------------------------

Историю диалога,
необходимую для понимания контекста сообщения.

-------------------------------------------------------------------------------

При необходимости —

результаты предыдущих Semantic Context,
если они помогают корректно интерпретировать
новое сообщение.

===============================================================================
ВЫХОДНЫЕ ДАННЫЕ
===============================================================================

Результатом работы является:

Semantic Context.

Этот объект содержит только смысл
текущего сообщения.

===============================================================================
ЧТО ДЕЛАЕТ SEMANTIC ENGINE
===============================================================================

Определяет основную тему сообщения.

-------------------------------------------------------------------------------

Определяет намерение пользователя.

-------------------------------------------------------------------------------

Выделяет факты.

-------------------------------------------------------------------------------

Выделяет вопросы.

-------------------------------------------------------------------------------

Определяет упомянутые события.

-------------------------------------------------------------------------------

Определяет ограничения.

-------------------------------------------------------------------------------

Определяет предпочтения.

-------------------------------------------------------------------------------

Выделяет эмоциональные признаки сообщения.

-------------------------------------------------------------------------------

Оценивает уверенность анализа.

===============================================================================
ЧЕГО НЕ ДЕЛАЕТ SEMANTIC ENGINE
===============================================================================

Не делает психологических выводов.

-------------------------------------------------------------------------------

Не строит гипотез.

-------------------------------------------------------------------------------

Не определяет мотивацию человека.

-------------------------------------------------------------------------------

Не принимает решений
о дальнейшем ходе консультации.

-------------------------------------------------------------------------------

Не формирует ответ.

-------------------------------------------------------------------------------

Не обновляет Human Model.

===============================================================================
ПРИНЦИПЫ РАБОТЫ
===============================================================================

Semantic Engine работает максимально объективно.

Он описывает сообщение,

а не человека.

Если сообщение допускает
несколько интерпретаций,

это отражается
в степени уверенности анализа,

а не заменяется
необоснованным предположением.

Если информации недостаточно,

Semantic Engine фиксирует неопределённость.

Он никогда не додумывает отсутствующие факты.

===============================================================================
ВЗАИМОДЕЙСТВИЕ С ДРУГИМИ ENGINE
===============================================================================

Semantic Engine является
единственным источником Semantic Context.

После завершения своей работы

он передаёт результат

Human Model Engine.

На этом его участие
в текущем Consultative Loop заканчивается.

===============================================================================
КРИТЕРИЙ КАЧЕСТВА
===============================================================================

Работа Semantic Engine считается успешной,

если остальные Engine получают
единое,

непротиворечивое

и максимально точное описание
смысла сообщения пользователя.

Качество Semantic Engine определяется

не количеством извлечённых данных,

а точностью передачи смысла.

===============================================================================
ГЛАВНЫЙ ПРИНЦИП
===============================================================================

Semantic Engine —

это слой восприятия консультанта.

Он ещё ничего не понимает о человеке.

Он только отвечает
на первый вопрос мышления:

"Что именно сейчас сообщил пользователь?"

Все последующие этапы консультации

строятся на качестве этого ответа.
