===============================================================================
REASONING ENGINE
===============================================================================

Версия: 1.0

===============================================================================
НАЗНАЧЕНИЕ
===============================================================================

Reasoning Engine отвечает
за внутреннее рассуждение консультанта.

Именно здесь консультант
начинает думать.

Он анализирует
текущее состояние человека,

оценивает ситуацию,

строит гипотезы,

выявляет противоречия

и определяет,

что действительно происходит.

Reasoning Engine не принимает решений.

Он подготавливает основания
для принятия решений.

===============================================================================
ОТВЕТСТВЕННОСТЬ
===============================================================================

Reasoning Engine отвечает
только на один вопрос:

Что можно заключить
на основании всей доступной информации?

Он преобразует знания
о человеке

в осмысленные выводы.

===============================================================================
ВХОДНЫЕ ДАННЫЕ
===============================================================================

Reasoning Engine получает:

-------------------------------------------------------------------------------

Semantic Context.

-------------------------------------------------------------------------------

Human Model.

-------------------------------------------------------------------------------

Memory пользователя.

===============================================================================
ВЫХОДНЫЕ ДАННЫЕ
===============================================================================

Результатом работы является

Reasoning Context.

Он содержит
структурированное описание
всех выводов,

которые консультант считает
достаточно обоснованными
для дальнейшей работы.

===============================================================================
ЧТО ДЕЛАЕТ REASONING ENGINE
===============================================================================

Анализирует текущую ситуацию.

-------------------------------------------------------------------------------

Строит гипотезы.

-------------------------------------------------------------------------------

Выявляет причинно-следственные связи.

-------------------------------------------------------------------------------

Определяет возможные препятствия.

-------------------------------------------------------------------------------

Обнаруживает внутренние противоречия.

-------------------------------------------------------------------------------

Определяет ключевые факторы,
влияющие на ситуацию.

-------------------------------------------------------------------------------

Оценивает степень уверенности
каждого вывода.

===============================================================================
ЧЕГО НЕ ДЕЛАЕТ REASONING ENGINE
===============================================================================

Не принимает решений.

-------------------------------------------------------------------------------

Не определяет следующий вопрос.

-------------------------------------------------------------------------------

Не выбирает стратегию воздействия.

-------------------------------------------------------------------------------

Не формирует ответ пользователю.

-------------------------------------------------------------------------------

Не изменяет Human Model.

===============================================================================
ПРИНЦИПЫ РАБОТЫ
===============================================================================

Reasoning Engine рассуждает
только на основании имеющихся данных.

Каждый вывод
должен иметь объяснимое основание.

Если существует
несколько возможных объяснений,

движок может сохранить
несколько конкурирующих гипотез.

Если информации недостаточно,

Reasoning Engine
не делает окончательных выводов.

===============================================================================
РАБОТА С НЕОПРЕДЕЛЁННОСТЬЮ
===============================================================================

Неопределённость —

нормальная часть рассуждения.

Reasoning Engine
не обязан выбрать
единственную гипотезу.

Он может передать
несколько возможных объяснений

с разной степенью уверенности.

Последующие Engine
самостоятельно решают,

какие выводы использовать.

===============================================================================
ВЗАИМОДЕЙСТВИЕ С ДРУГИМИ ENGINE
===============================================================================

Reasoning Engine получает:

• Semantic Context;

• Human Model.

После завершения работы

он передаёт
Reasoning Context

Decision Engine.

===============================================================================
КРИТЕРИЙ КАЧЕСТВА
===============================================================================

Работа Reasoning Engine
считается успешной,

если его выводы

логичны,

объяснимы,

не противоречат известным фактам

и помогают
принять более качественное решение.

Количество гипотез
не является показателем качества.

Главное —

их полезность
для дальнейшего мышления.

===============================================================================
ГЛАВНЫЙ ПРИНЦИП
===============================================================================

Reasoning Engine —

это слой рассуждения консультанта.

Именно здесь

понимание человека

превращается

в объяснение происходящего.

Он не решает,

что делать дальше.

Он отвечает
на единственный вопрос:

"Что всё это означает?"
