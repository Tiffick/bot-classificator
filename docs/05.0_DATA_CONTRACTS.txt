ЗАЧЕМ СУЩЕСТВУЕТ ЭТОТ ДОКУМЕНТ
===============================================================================

Этот документ описывает систему внутренних контрактов данных,
используемых AI Consultant.

Data Contract определяет структуру информации,
которой обмениваются Engine.

Контракты позволяют каждому Engine работать независимо,
используя единый формат данных.

Архитектура определяет компоненты системы.

Consultative Loop определяет последовательность их работы.

Data Contracts определяют,
какие данные проходят между компонентами.

===============================================================================
ЧТО ТАКОЕ DATA CONTRACT
===============================================================================

Data Contract —

это формальное описание объекта данных,
который используется внутри системы.

Контракт определяет:

• назначение объекта;

• ответственность объекта;

• владельца объекта;

• правила изменения объекта.

Data Contract не описывает программную реализацию.

Он описывает только логическую модель данных.

===============================================================================
ПРИНЦИПЫ DATA CONTRACTS
===============================================================================

Каждый контракт отвечает только за одну область ответственности.

Каждый объект имеет одного владельца.

Каждый Engine получает объект,
обрабатывает его
и передаёт следующему Engine.

Engine не должны изменять данные,
которые им не принадлежат.

Все изменения происходят только через соответствующий Engine.

===============================================================================
СОСТАВ DATA CONTRACTS
===============================================================================

Система использует следующие основные контракты.

-------------------------------------------------------------------------------

05.1_SEMANTIC_CONTEXT

Результат анализа пользовательского сообщения.

-------------------------------------------------------------------------------

05.2_HUMAN_MODEL

Текущее понимание личности пользователя.

-------------------------------------------------------------------------------

05.3_REASONING_CONTEXT

Результаты анализа,
гипотез
и логических выводов.

-------------------------------------------------------------------------------

05.4_DECISION_CONTEXT

Описание принятого решения
о следующем действии консультанта.

-------------------------------------------------------------------------------

05.5_IMPACT_CONTEXT

Описание ожидаемого эффекта,
который должен произвести следующий ответ.

-------------------------------------------------------------------------------

05.6_EMOTIONAL_CONTEXT

Описание эмоциональных характеристик
будущего ответа.

===============================================================================
ГЛАВНЫЙ ПРИНЦИП
===============================================================================

Data Contracts являются языком общения Engine.

Engine взаимодействуют
не напрямую друг с другом,

а через строго определённые контракты данных.

Изменение любого контракта
должно быть согласовано
со всеми компонентами,
использующими этот объект.
