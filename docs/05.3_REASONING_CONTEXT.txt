===============================================================================
REASONING CONTEXT
===============================================================================

Версия: 1.0

===============================================================================
НАЗНАЧЕНИЕ
===============================================================================

Reasoning Context содержит результаты анализа,
выполненного Reasoning Engine.

Он описывает текущее рассуждение консультанта.

Reasoning Context не принимает решений.

Не формирует ответ.

Не определяет стиль общения.

Его задача —

объяснить,

к каким выводам пришла система,
анализируя Human Model.

===============================================================================
ОТВЕТСТВЕННОСТЬ
===============================================================================

Reasoning Context отвечает только на один вопрос:

Что консультант понял после анализа человека?

Он содержит результаты размышления,

но не содержит выбранного дальнейшего действия.

===============================================================================
ВЛАДЕЛЕЦ
===============================================================================

Создаётся:

Reasoning Engine.

Изменяется:

только Reasoning Engine.

Все остальные Engine используют его
только для чтения.

===============================================================================
СОДЕРЖАНИЕ
===============================================================================

Reasoning Context может содержать:

-------------------------------------------------------------------------------

Основные выводы.

-------------------------------------------------------------------------------

Рабочие гипотезы.

-------------------------------------------------------------------------------

Подтверждённые гипотезы.

-------------------------------------------------------------------------------

Опровергнутые гипотезы.

-------------------------------------------------------------------------------

Неопределённости.

-------------------------------------------------------------------------------

Противоречия.

-------------------------------------------------------------------------------

Недостающую информацию.

-------------------------------------------------------------------------------

Степень уверенности
в каждом выводе.

-------------------------------------------------------------------------------

Наиболее важные направления
для дальнейшего исследования.

===============================================================================
ПРИНЦИПЫ
===============================================================================

Reasoning Context описывает процесс мышления.

Он не принимает решений.

Если существует несколько возможных объяснений,

они могут одновременно присутствовать
в Reasoning Context.

Система не обязана выбирать одну гипотезу,
пока для этого недостаточно информации.

Неопределённость считается нормальным состоянием.

===============================================================================
ЖИЗНЕННЫЙ ЦИКЛ
===============================================================================

Каждый Consultative Loop
создаёт новый Reasoning Context.

Он существует только
в рамках текущего цикла консультации.

После передачи следующему Engine
Reasoning Context становится частью истории консультации
и больше не изменяется.

===============================================================================
ИСПОЛЬЗОВАНИЕ
===============================================================================

Decision Engine использует
Reasoning Context

для выбора следующего действия.

-------------------------------------------------------------------------------

Impact Engine использует
Reasoning Context

для определения наиболее полезного воздействия.

===============================================================================
ГЛАВНЫЙ ПРИНЦИП
===============================================================================

Reasoning Context —

это внутреннее рассуждение консультанта.

Он показывает,

что система считает вероятным,

что считает доказанным,

что считает сомнительным,

и чего ей пока не хватает
для более глубокого понимания человека.

Reasoning Context является переходом

от понимания человека

к принятию решения.
