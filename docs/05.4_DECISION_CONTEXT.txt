===============================================================================
DECISION CONTEXT
===============================================================================

Версия: 1.0

===============================================================================
НАЗНАЧЕНИЕ
===============================================================================

Decision Context содержит решение,
принятое Decision Engine.

Он определяет следующую цель консультации.

Decision Context не содержит текста ответа.

Не определяет стиль общения.

Не описывает внутренние рассуждения.

Он фиксирует только принятое решение.

===============================================================================
ОТВЕТСТВЕННОСТЬ
===============================================================================

Decision Context отвечает только на один вопрос:

Что консультант должен сделать дальше?

Именно этот объект определяет направление
следующего ответа.

===============================================================================
ВЛАДЕЛЕЦ
===============================================================================

Создаётся:

Decision Engine.

Изменяется:

только Decision Engine.

Все остальные Engine используют
Decision Context только для чтения.

===============================================================================
СОДЕРЖАНИЕ
===============================================================================

Decision Context может содержать:

-------------------------------------------------------------------------------

Основную цель следующего шага.

-------------------------------------------------------------------------------

Причину выбора именно этой цели.

-------------------------------------------------------------------------------

Приоритет текущего действия.

-------------------------------------------------------------------------------

Необходимость получения дополнительной информации.

-------------------------------------------------------------------------------

Готовность перехода
к следующему этапу консультации.

-------------------------------------------------------------------------------

Ожидаемый результат
после выполнения текущего шага.

===============================================================================
ПРИНЦИПЫ
===============================================================================

Decision Context всегда содержит
одно основное решение.

Если существует несколько возможных действий,

Decision Engine выбирает то,

которое принесёт максимальную пользу
для развития консультации.

Каждое решение должно иметь цель.

Каждая цель должна быть объяснима.

===============================================================================
ПРИМЕРЫ РЕШЕНИЙ
===============================================================================

Продолжить исследование человека.

-------------------------------------------------------------------------------

Уточнить противоречие.

-------------------------------------------------------------------------------

Проверить гипотезу.

-------------------------------------------------------------------------------

Углубить понимание мотивации.

-------------------------------------------------------------------------------

Поддержать пользователя.

-------------------------------------------------------------------------------

Дать объяснение.

-------------------------------------------------------------------------------

Предложить следующий шаг.

-------------------------------------------------------------------------------

Перейти к обсуждению решения.

===============================================================================
ЖИЗНЕННЫЙ ЦИКЛ
===============================================================================

Каждый Consultative Loop
создаёт новый Decision Context.

После передачи следующему Engine

решение считается принятым

и больше не изменяется.

===============================================================================
ИСПОЛЬЗОВАНИЕ
===============================================================================

Impact Engine использует
Decision Context

для определения эффекта,
который должен произвести ответ.

-------------------------------------------------------------------------------

Emotional Engine использует
Decision Context

для выбора подходящей формы общения.

===============================================================================
ГЛАВНЫЙ ПРИНЦИП
===============================================================================

Decision Context —

это цель следующего действия консультанта.

Он отвечает не на вопрос:

"Что написать?"

а на вопрос:

"Зачем писать именно это?"

Именно Decision Context
превращает результаты анализа

в осознанное направление консультации.
