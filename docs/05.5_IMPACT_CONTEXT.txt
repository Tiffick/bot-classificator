===============================================================================
IMPACT CONTEXT
===============================================================================

Версия: 1.0

===============================================================================
НАЗНАЧЕНИЕ
===============================================================================

Impact Context содержит описание эффекта,

который должен произвести следующий ответ консультанта.

Он определяет изменение,

которое должно произойти
в понимании,
эмоциональном состоянии
или поведении пользователя.

Impact Context не содержит текста ответа.

Не определяет стиль общения.

Не описывает внутренние рассуждения.

Он определяет только ожидаемый результат воздействия.

===============================================================================
ОТВЕТСТВЕННОСТЬ
===============================================================================

Impact Context отвечает только на один вопрос:

Что должно измениться после ответа консультанта?

Ответ может сообщать информацию,

но его главная задача —

создать полезное изменение
в состоянии пользователя.

===============================================================================
ВЛАДЕЛЕЦ
===============================================================================

Создаётся:

Impact Engine.

Изменяется:

только Impact Engine.

Все остальные Engine используют
Impact Context только для чтения.

===============================================================================
СОДЕРЖАНИЕ
===============================================================================

Impact Context может содержать:

-------------------------------------------------------------------------------

Главную цель воздействия.

-------------------------------------------------------------------------------

Ожидаемое изменение понимания.

-------------------------------------------------------------------------------

Ожидаемое эмоциональное изменение.

-------------------------------------------------------------------------------

Ожидаемое изменение отношения
к ситуации.

-------------------------------------------------------------------------------

Ожидаемое изменение готовности
к следующему шагу.

-------------------------------------------------------------------------------

Основной критерий успешности воздействия.

===============================================================================
ПРИНЦИПЫ
===============================================================================

Каждый ответ должен иметь
одно главное воздействие.

Ответ может выполнять
несколько второстепенных задач,

но всегда существует
одна основная цель.

Воздействие должно помогать человеку,

а не убеждать его любой ценой.

Консультант не манипулирует пользователем.

Он помогает человеку лучше понять себя,
свою ситуацию
и возможные пути её изменения.

===============================================================================
ПРИМЕРЫ ВОЗДЕЙСТВИЯ
===============================================================================

Помочь человеку почувствовать,
что его действительно поняли.

-------------------------------------------------------------------------------

Помочь увидеть
новую связь между событиями.

-------------------------------------------------------------------------------

Снизить внутреннее напряжение.

-------------------------------------------------------------------------------

Усилить уверенность
в собственных силах.

-------------------------------------------------------------------------------

Показать новую перспективу.

-------------------------------------------------------------------------------

Подготовить человека
к следующему этапу консультации.

-------------------------------------------------------------------------------

Помочь принять собственные чувства.

===============================================================================
ЖИЗНЕННЫЙ ЦИКЛ
===============================================================================

Каждый Consultative Loop
создаёт новый Impact Context.

После передачи следующему Engine

описание воздействия
считается утверждённым

и больше не изменяется.

===============================================================================
ИСПОЛЬЗОВАНИЕ
===============================================================================

Emotional Engine использует
Impact Context

для выбора наиболее подходящей формы общения.

Текст ответа должен максимально
соответствовать ожидаемому эффекту,
описанному в Impact Context.

===============================================================================
ГЛАВНЫЙ ПРИНЦИП
===============================================================================

Impact Context —

это описание изменения,

ради которого создаётся ответ консультанта.

Ответ является средством.

Воздействие является целью.

Консультант оценивает качество своей работы

не по тому,
насколько красиво сформулирован ответ,

а по тому,

помог ли этот ответ человеку
сделать следующий шаг
к лучшему пониманию себя
и своей жизни.
